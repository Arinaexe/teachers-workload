# Нагрузка учителей

Дашборд для учителей (отмечают проведённые занятия) и Арины (видит нагрузку по всем сразу).

Стек: Google-таблица (база) + Google Apps Script (бесплатный API поверх таблицы) + статический сайт (этот репозиторий) на GitHub Pages.

## Как это устроено

- Таблица **Нагрузка_Учителей** в Google Drive — источник данных. Три листа:
  - **Учителя** — Имя, PIN, Предмет, Активен. Здесь заводишь реальных учителей (замени пример).
  - **Занятия** — расписание. Сюда сама вносишь занятия заранее (Учитель, Ученик, Дата, Время, Статус=Запланировано). Учителя через дашборд меняют только Статус.
  - **Сводка** — живые формулы, число занятий по каждому учителю (дублирует то, что показывает дашборд, на случай если открываешь просто таблицу).
- `apps-script/Code.gs` — код API. Разворачивается как контейнерный скрипт прямо внутри таблицы (Extensions → Apps Script), не отдельно.
- `index.html` / `style.css` / `app.js` — сам дашборд, статика, деплой на GitHub Pages.

## Установка (разово, минут 10)

Это единственная часть, которую нельзя автоматизировать — Google требует ручного подтверждения при первом деплое скрипта.

1. Открой таблицу **Нагрузка_Учителей** в своём Google Drive.
2. **Учителя**: удали 2 примерных строки, впиши реальных учителей — Имя, придуманный тобой 4-значный PIN, предмет (по желанию), Активен=TRUE. PIN потом сообщи каждому учителю лично (не через таблицу и не публично).
3. **Занятия**: удали примерные строки, начни вносить реальное расписание (Учитель — точно как в листе Учителя, Ученик, Дата ГГГГ-ММ-ГГГГ, Время, Статус=Запланировано). Дальше учитель сам меняет статус через дашборд.
4. В таблице: **Extensions → Apps Script**. Откроется редактор скрипта, там уже будет пустой `Code.gs` — сотри содержимое и вставь целиком код из `apps-script/Code.gs` этого репозитория.
5. В самом верху вставленного кода в функции `setupAdmin()` замени `'0000'` на свой личный PIN (это твой вход как админа, имя останется "Арина"). Сохрани (Ctrl+S).
6. В панели выбери функцию `setupAdmin` из выпадающего списка вверху → нажми **Run**. Google спросит разрешения — разреши (это твой скрипт и твоя таблица, стандартный запрос доступа). Эта функция запускается один раз.
7. **Deploy → New deployment** → шестерёнка рядом с "Select type" → **Web app**. Execute as: **Me**. Who has access: **Anyone**. Deploy.
8. Google выдаст **Web app URL** — скопируй его целиком.
9. В файле `app.js` этого репозитория замени строку `var API_URL = 'ВСТАВЬ_СЮДА_URL...'` на этот URL, сохрани, запушь в GitHub (или попроси об этом в следующем сообщении — доделаю за тебя, если пришлёшь URL).

Готово — дашборд на GitHub Pages начинает работать с реальными данными.

## Повседневное использование

- Новое занятие — просто добавь строку в **Занятия** напрямую в таблице.
- Учитель заходит на сайт дашборда, вводит имя + PIN, видит свои занятия, жмёт «Отметить проведённым».
- Ты заходишь под именем «Арина» + свой PIN — видишь сводку нагрузки по всем и полный список занятий с фильтром по статусу.
- Порог "перегруза" в сводке — переменная `OVERLOAD_THRESHOLD` в начале `app.js` (сейчас 8 запланированных занятий). Поменяй под свою норму.

## Если что-то меняется

- Изменить/удалить учителя — правь строку в листе **Учителя** таблицы напрямую, дашборд ничего кешировать не будет.
- Изменить логику API — правь `Code.gs` прямо в Apps Script редакторе (Extensions → Apps Script в таблице) и делай **Deploy → Manage deployments → Edit → New version** заново — иначе изменения не применятся к уже выданному URL.
- Изменить вид сайта — правь `index.html`/`style.css`/`app.js` в этом репозитории и пуш в `main`, Pages подхватит сам за ~1 минуту.
